# Pet Shop

Aplicação fullstack de e-commerce para pet shop, desenvolvida com Next.js, Prisma, PostgreSQL e Docker.

## Tecnologias

- [Next.js](https://nextjs.org/) — framework React com SSR
- [Prisma](https://www.prisma.io/) — ORM para acesso ao banco de dados
- [PostgreSQL](https://www.postgresql.org/) — banco de dados relacional
- [Docker](https://www.docker.com/) — containerização do ambiente
